## Users (Laravel)

| User | Job |
| --- | --- |
| **Admin** | Everything including buy into stock |
| **Accountant** | Buy/receive into کۆگا; review sales; **send** goods; reports |
| **Collector** | Wholesale or Retail sell + print; collect; own reports |

Stock path: **buy → کۆگا → sell (paper) → send (real goods)**.

## Next.js (reference only)

The root Next.js / Prisma / PostgreSQL app is **archived as design & behaviour reference**. It does **not** deploy to the Enterprise cPanel host.

See **[REFERENCE-NEXTJS.md](REFERENCE-NEXTJS.md)**. Do not treat root `npm run dev` as the production system.
